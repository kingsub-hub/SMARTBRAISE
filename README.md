#SMARTBRAISE RDC

## Présentation
SMARTBRAISE RDC est une application web de gestion de production, de stock, de commandes et de livraison de braises écologiques.
Le projet vise à moderniser la gestion des activitéés liées à la production et à la commercialisation de braises en République Démocratique du Congo.

---

## problématique
Dans de nombreuses entreprises de production de braises; la gestion est encore réalisée manuellement :
-suivi du stock dans des cahiers ;
-enregistrement manuel des commandes ;
-difficulté à controler les liraisons ;
